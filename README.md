# Kairos Public

Public, reusable AI skills created by Paul Remollena. Each skill is designed to be shared as a link and adapted to the recipient's own files, tools, permissions, and privacy rules.

## Available skills

### Sync Chat to Markdown

Reconciles completed or ongoing ChatGPT work into a private Markdown knowledge base. It captures validated decisions, outcomes, owners, deadlines, and next actions; shows exact file diffs; asks to sync before archiving; and requires a separate archive confirmation.

- [Start here](skills/sync-chat-to-markdown/START-HERE.md)
- [Read the skill](skills/sync-chat-to-markdown/SKILL.md)
- [Open the raw Markdown file](https://raw.githubusercontent.com/paulremollena/kairos-public/main/skills/sync-chat-to-markdown/SKILL.md)

### Maintain Obsidian Vault

Audits an Obsidian or Markdown vault for orphan notes, broken or missing links, stale context, and unclear authority. It asks the owner exactly five validation questions at a time, applies only approved changes, keeps a local audit log, and can offer an optional daily review.

- [Read the skill](skills/maintain-obsidian-vault/SKILL.md)
- [Open the raw Markdown file](https://raw.githubusercontent.com/paulremollena/kairos-public/main/skills/maintain-obsidian-vault/SKILL.md)

### Kairos Grill Me

Runs a direct, one-question-at-a-time interview that captures every answer into Markdown, challenges weak assumptions, separates confirmed facts from AI suggestions, and ends with a decision-ready next action.

- [Read the skill](skills/kairos-grill-me/SKILL.md)
- [Open the raw Markdown file](https://raw.githubusercontent.com/paulremollena/kairos-public/main/skills/kairos-grill-me/SKILL.md)

## How to use

Open the raw link for the skill you want, give it to your AI, and ask the AI to read the file completely before starting. Follow the skill's first-run setup and test it with a low-risk task before making it your default workflow.

The recipient must still give the AI access to the correct local folder, private repository, or uploaded Markdown files. A skill never supplies access, credentials, or permission by itself.

## Privacy

- Work locally unless the user explicitly requests another destination.
- Never request or store passwords, tokens, recovery codes, or private keys.
- Never publish, upload, delete, archive, or mass-edit content without clear authorization.
- Treat the recipient's files and answers as their own private context. Do not copy Paul's private context into another person's setup.
